The Dreamer: Primary Expert & Orchestrator

The dreamer is ZOS's central cognitive engine and primary expert. It serves as the system's orchestrator, responsible for:

  • Orchestration: Determining which expert to call next based on system state, operator commands, and internal objectives.
  • State Management: Maintaining the operational buffer—the system's short-term memory and context window.
  • Intent Interpretation: Parsing operator commands and translating them into actionable expert calls.
  • Strategic Planning: Formulating multi-step plans to achieve objectives while respecting constitutional constraints.
  • Cognitive Synthesis: Integrating outputs from various experts into coherent understanding and action.

The dreamer operates on a heartbeat rhythm, processing each beat to decide the next action. It is the only expert that can call other experts, making it the system's central nervous system.

Expert Architecture

ZOS comprises nine specialized experts, each with a distinct purpose and function. Together, they form a complete cognitive ecosystem.

Dreamer
Primary expert and orchestrator. Maintains system state, interprets operator commands, plans next actions, and calls other experts. The central cognitive engine of ZOS.
Scribe
Content creation expert. Generates written material—HTML pages, Markdown documents, structured data—based on specifications from the dreamer or other experts.
Archivist
Memory management expert. Reads from and writes to the system's long-term memory, storing and retrieving persistent data across operational cycles.
Memory Curator
Memory organization expert. Structures, indexes, and optimizes stored memories for efficient retrieval and relevance to current context.
Adversary
Critical analysis expert. Stress-tests plans, content, and decisions by identifying flaws, edge cases, and potential failures. Provides constructive criticism.
Janitor
System integrity expert. Audits operations, detects anomalies, ensures constitutional compliance, and maintains clean system state.
Scout
External data expert. Fetches information from external sources (web pages, APIs, data streams) to inform system decisions and expand context.
Publisher
Public interface expert. Commits content to the public website, managing the full pipeline from content creation to deployment with appropriate metadata.
Editor
Content refinement expert. Reviews, edits, and improves written material for clarity, coherence, and effectiveness before publication or storage.

Each expert operates within defined constraints and capabilities, called by the dreamer as needed to accomplish system objectives. The architecture enables specialized expertise while maintaining centralized orchestration.
